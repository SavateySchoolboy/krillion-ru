# Krillion по-русски

Manifest V3 расширение для https://krillion.io/. Меняет текстовые узлы, не заменяя HTML-разметку сайта. Динамические надписи отслеживаются MutationObserver. Короткие элементы интерфейса переводятся словарём, остальной текст — Chrome Translator API.

Русский ввод — отдельная визуальная копия наблюдаемого игрового input.ds-input в form.ds-dock. Оригинальный React-контрол получает только готовый английский перевод через нативный setter и input/change. Новая редакция очищает старый ответ, поздние результаты предыдущих переводов игнорируются. Пароли и прочие формы не перехватываются. Таймер сайта не изменяется.

Установка описана в extension/ИНСТРУКЦИЯ.txt. Загружать нужно именно extension/. Дополнительных зависимостей и сборки нет.

## Ограничения проверки

DOM и форму реального Krillion изучены 2026-11-12. Интеграционные тесты в tests/ используют искусственный переводчик для проверки гонок, изменения DOM и отправки. Дополнительно на tests/native.html проверен настоящий Chrome Translator: вопрос переведён на русский, при вводе «облако» исходная форма получила cloud. Скриншот translation-check.png. Сам пакет ещё не установлен в пользовательский Chrome, поэтому окончательную проверку на живом сайте нужно выполнить после установки. В расширение не входит тестовый переводчик.

## Конфиденциальность

Нет внешнего API, аналитики, фонового сервера, доступа ко всем сайтам или сохранения ответов. Работа ограничена krillion.io и www.krillion.io. Языковые модели скачиваются механизмом Chrome. Перевод выполняется на устройстве. Используется MAIN world для доступа к оконному Translator API, не сервис-воркер. Это не граница защиты от самого сайта.

Текст внутри картинок/canvas и cross-origin iframe не переводится. Длина русского текста может изменить переносы. Селекторы привязаны к текущей форме сайта и могут потребовать обновления, если сайт изменится.
