# Krillion по-русски

Manifest V3 расширение для https://krillion.io/. Меняет текстовые узлы, не заменяя HTML-разметку сайта. Динамические надписи отслеживаются MutationObserver. Короткие элементы интерфейса переводятся словарём, остальной текст — Chrome Translator API.

Русский ввод показывается в отдельной визуальной копии игрового поля. Оригинальный React-контрол получает только готовый английский перевод через нативный setter и input/change. Поддерживаются обычная HTML-форма и игровое поле без формы с отдельной кнопкой отправки (включая сценарий Puffer Party). Новая редакция очищает старый ответ, поздние результаты предыдущих переводов игнорируются. Поля имени и кода комнаты в лобби не перехватываются. Таймер сайта не изменяется.

Установка описана в extension/ИНСТРУКЦИЯ.txt. Загружать нужно именно extension/. Дополнительных зависимостей и сборки нет.

## Ограничения проверки

Обычная игровая форма Krillion изучена 2026-11-12. Интеграционный стенд `tests/index.html` проверяется в Chrome с искусственным переводчиком: обычная форма, поле Puffer Party без формы, отдельная кнопка, Enter, гонки переводов, ошибки и исключение полей лобби. Реальный Chrome Translator ранее проверен на `tests/native.html`: исходная форма получила `cloud` для ответа «облако». Текущий сайт Puffer Party в этом исправлении проверить не удалось, поэтому его DOM и реальную отправку нужно подтвердить после разрешения доступа к странице. В расширение не входит тестовый переводчик.

## Конфиденциальность

Нет внешнего API, аналитики, фонового сервера, доступа ко всем сайтам или сохранения ответов. Работа ограничена krillion.io и www.krillion.io. Языковые модели скачиваются механизмом Chrome. Перевод выполняется на устройстве. Используется MAIN world для доступа к оконному Translator API, не сервис-воркер. Это не граница защиты от самого сайта.

## Документация

- https://developer.chrome.com/docs/ai/translator-api
- https://developer.chrome.com/docs/extensions/reference/manifest/content-scripts

Текст внутри картинок/canvas и cross-origin iframe не переводится. Длина русского текста может изменить переносы. Селекторы привязаны к текущей форме сайта и могут потребовать обновления, если сайт изменится.
